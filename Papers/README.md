# Reference inventory

- `MV_Currency_Factors.pdf` - Fan, Kearney, Li, and Liu (2026), *Rethinking currency factors: The case for mean-variance optimisation*. Used for the baseline carry, three-month momentum, five-year value, portfolio, and idiosyncratic-volatility conventions.
- `Forecast_Bias_Infl.pdf` - Zobaran, *Forecast bias across horizons: Inflation expectations and the Treasury yields*. Retained for the future yield-curve phase; it is not used by the FX pipeline.

External live documentation is linked in `docs/METHODOLOGY.md` rather than copied into the repository, preventing stale duplicate reference files.
